#### 🧵 Main Focus — Tsumugi

- **[Tsumugi](https://github.com/kamonabe/Tsumugi)** — an embeddable scripting language in Rust.
  Runs business rules and extension logic inside a host application, **predictably and auditably**,
  within the permissions and execution budget the host grants.
  Host stability first · deny-by-default capabilities · budgets for every run · predictability over raw speed.
  → [Manifesto](https://github.com/kamonabe/Tsumugi/blob/main/docs/manifesto.md)
- It's also an experiment in **fully AI-driven, spec-driven development**:
  every line — code and docs — is written by AI, guided by the manifesto and specs.
  A scheduled loop designs, implements, and opens PRs; I review, decide, and steer via issues.
